# xelements

یک جعبه‌ابزار ماژولار و فارسی بر پایه Next.js، App Router، TypeScript و Tailwind CSS.

## رابط فارسی و RTL

- زبان ریشه سند روی `fa` تنظیم شده است.
- جهت کلی رابط `RTL` است.
- متن‌های صفحه اصلی، هدر، فوتر، متادیتا و دو ابزار نمونه فارسی شده‌اند.
- بخش‌هایی که ذاتاً باید چپ‌به‌راست بمانند، مثل رمز عبور، عبارت‌های ماشین حساب و برند `xelements`، به‌صورت موضعی `LTR` هستند.
- پشته فونت برای فونت‌های رایج فارسی مانند `Vazirmatn`، `IRANSansX` و `Dana` آماده شده و در نبود آن‌ها از فونت‌های سیستمی استفاده می‌کند.

## هویت بصری

لوگوی اصلی بدون بازطراحی یا تغییر رنگ استفاده شده است:

- `public/brand/xelements-logo-source.png` — فایل اصلی لوگوی ارسالی.
- `public/brand/xelements-logo.png` — نسخه مناسب استفاده responsive در رابط.
- `public/brand/xelements-mark.png` — نماد X استخراج‌شده از لوگوی اصلی برای Navbar.

پالت رابط از طیف سبز/زمردی لوگو گرفته شده و در کنار خنثی‌های Zinc استفاده می‌شود.

## معماری

متادیتای ابزارها در `lib/tools.ts` قرار دارد. هر ابزار رابط کاربری و منطق مستقل خودش را در `modules/<tool>` نگه می‌دارد و route مربوط به آن در `app/tools/<slug>` قرار می‌گیرد.

برای افزودن ابزار جدید:

1. پوشه `modules/<new-tool>` را بسازید.
2. کامپوننت UI و فایل منطق مستقل ابزار را اضافه کنید.
3. route جدید را در `app/tools/<new-tool>/page.tsx` ایجاد کنید.
4. یک ورودی به `lib/tools.ts` اضافه کنید تا ابزار در صفحه اصلی نمایش داده شود.

## ابزارهای فعلی

- سازنده رمز عبور
  - طول 8 تا 64 کاراکتر
  - حروف بزرگ، حروف کوچک، عدد و نماد
  - استفاده از random امن مرورگر در صورت دسترسی
  - کپی با یک کلیک
  - تخمین قدرت رمز
- ماشین حساب
  - جمع، تفریق، ضرب و تقسیم
  - ورودی اعشاری، تغییر علامت، پاک‌کردن و Backspace
  - پشتیبانی از صفحه‌کلید
  - منطق reducer/state-machine بدون `eval()`

## فونت فارسی Yekan Bakh

رابط کاربری برای استفاده از **Yekan Bakh** به‌صورت self-hosted تنظیم شده است. فایل‌های `woff2` را از نسخه‌ی محلی/دارای مجوز خود در مسیر `public/fonts/` قرار دهید. نگاشت وزن‌ها در `app/globals.css` آماده است:

- Regular → 400
- Bold → 700
- Heavy → 800
- Fat → 900

فایل‌های فونت در بسته‌ی خروجی بازتوزیع نشده‌اند؛ پوشه و تنظیمات لازم از قبل آماده است.
