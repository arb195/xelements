# Yekan Bakh local font files

The project is configured to self-host Yekan Bakh from this directory.
Place these files here from your own licensed/local copy:

- `YekanBakh-Regular.woff2`
- `YekanBakh-Bold.woff2`
- `YekanBakh-Heavy.woff2`
- `YekanBakh-Fat.woff2`

The CSS in `app/globals.css` already maps them to weights 400, 700, 800, and 900.
